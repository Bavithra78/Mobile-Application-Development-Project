# MAD Mini Projects – Unique Programs Only

This archive groups the distinct program topics from SET I, SET II and SET III. Repeated questions are included once only. Each program folder contains Java/XML starter files and an illustrative Android-style output preview.

## Folder rules
- `Set-1`: distinct topics first appearing in SET I.
- `Set-2`: only topics not already present in SET I (Dice Rolling and College Canteen Management).
- `Set-3`: no new topic remains after comparing against SET I and SET II, so it contains a reference note only.

## Android Studio usage
1. Create a new Android Studio project using **Java**.
2. Copy the folder's Java code into `MainActivity.java` and its XML into `app/src/main/res/layout/activity_main.xml`.
3. Change the package declaration to match your project.
4. For advanced Android APIs, add the permissions/dependencies and lifecycle handling required by the question.
5. Build and test on an emulator or device.

**Note:** These are compact starter references for learning and customization, not a single ready-to-install APK. Output PNGs are illustrative UI previews, not screenshots captured from Android Studio.
