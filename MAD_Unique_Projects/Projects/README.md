# MAD Projects – Android Applications

## About the Project

This repository contains a collection of Android mini applications developed using Android Studio, Java, and XML. The main objective of these applications is to explore Android application development and implement different mobile app functionalities through practical development.

Each application focuses on a particular concept, including user interaction, input handling, calculations, UI design, data processing, and Android components.

## Technologies Used

- **Programming Language:** Java
- **UI Design:** XML
- **IDE:** Android Studio
- **Platform:** Android
- **Development Approach:** Native Android Application Development

## How to Run the Applications

1. Install Android Studio.
2. Download or clone this repository.
3. Open the required Android application project in Android Studio.
4. Allow Gradle synchronization to complete.
5. Start an Android Emulator or connect an Android device.
6. Run the application to explore its functionality.
