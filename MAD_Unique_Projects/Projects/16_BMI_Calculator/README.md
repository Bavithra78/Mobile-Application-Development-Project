Calculates BMI from weight in kg and height in meters.

## Important setup note
These are compact classroom starter snippets, not complete standalone Android Studio projects. Create an Android Java project, place the Java class in your app package, copy the XML into `res/layout/activity_main.xml`, and update the package name. Some advanced tasks (sensor, location/map, wallpaper, TextToSpeech, dialer) need the permissions, lifecycle callbacks, runtime permission handling, dependencies, and extra controls described in the source question. The comments identify where platform-specific setup is required. Test on an emulator/device before submission.
